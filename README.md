# Zotero Archiver

把 Zotero 论文**归档**到独立的命名归档库，完整保留标签、笔记、附件、集合等所有信息；支持**定期自动归档**（自动生成「备份 YYYY-MM-DD」归档库），随时一键切换查看、需要时可一键恢复到主库。

> 核心思路：**数据目录快照** —— 直接复制 `zotero.sqlite` + `storage/` + 附件，字节级保留所有信息，不经过导出/导入（导出会重置时间、断开 Word 引用、丢关联）。

---

## 核心功能

### 1. 归档所选论文（右键菜单）

选中一篇或多篇论文 → 右键 → **归档**：

1. 输入归档库名称（如「归档 20261015」）。
2. 插件**完整快照**主库到该归档库。
3. 自动**清理**归档库中未选中的论文（归档库只留你选中的）。
4. 主库中的论文自动标记 **「已归档」** 标签。

归档后主库可保留原文（已标记），也可以随时「批量删除已归档论文」释放空间——归档库里始终有完整副本。

### 2. 定期自动归档（定期备份）

设置页开启**定期备份**：

- 每隔 N 天（默认 30 天），在指定时间（默认凌晨 3 点）自动生成「**备份 YYYY-MM-DD**」归档库。
- 只在主库生效，静默后台完成，无需手动操作。

### 3. 其他功能

| 功能 | 入口 | 说明 |
|---|---|---|
| 切换文库 | 设置页「文库」列表 | 主库 ⇄ 各归档库一键切换（自动重启，零导入） |
| 恢复到主库 | 归档库右键「恢复到主库」 | 所选论文回主库，**含附件**，自动归入同名集合 |
| 批量删除已归档论文 | 设置页按钮 | 删除主库中已标记「已归档」的论文及其附件文件 |

## 安装

1. 下载 `zotero-archiver.xpi`（本项目 `plugin/` 目录，或 Releases 页）。
2. Zotero → **工具 → 插件** → 右上角齿轮 → **Install Plugin From File...** → 选择 xpi。
3. 重启 Zotero。

---

## 使用

### 归档所选论文

1. 主库选中论文 → 右键 → **归档**。
2. 输入归档库名称，确认。
3. Zotero 自动退出 → 后台复制 → 重开归档库 → 清理未选中 →（切回主库后）自动标记「已归档」。

### 定期归档

1. **编辑 → 设置 → Zotero Archiver**。
2. 勾选「启用定期备份」，设置天数和时间。
3. 到时间会自动生成「备份 YYYY-MM-DD」归档库。

## 路径配置

插件默认路径如下（如你的环境不同，请修改 `plugin/addon/zotero-archiver.js` 顶部的常量）：

| 项 | 默认值 |
|---|---|
| 主库数据目录 | `D:/OneDrive/Zotero`（`MAIN_DATA_DIR`） |
| 主库 profile | `C:/Users/Administrator/AppData/Roaming/Zotero/Zotero/Profiles/jdl6eimd.default`（`MAIN_PROFILE`） |
| Zotero 程序 | `C:/Program Files/Zotero/zotero.exe`（`ZOTERO_EXE`） |
| 归档库根目录 | `D:/Zotero-Archive`（`DEFAULT_ARCHIVE_ROOT`，也可在设置页修改） |

归档库按「名称」分目录存放：`D:/Zotero-Archive/<名称>/data` + `/profile` + `/attachments`。

---

## 原理（简要）

- **归档** = 把主库数据目录**完整复制**到归档库（`zotero.sqlite` + `storage/` + 附件），字节级忠实。
- **切换** = 用不同 profile 打开主库/归档库（Zotero 单进程只能挂一个库，切换必然重启一次，插件已自动化）。
- **恢复** = 归档库导出所选（RDF）→ 主库导入（新建条目）+ 复制附件文件 + 归入同名集合。

## 常见问题

- **归档后 Zotero 直接关掉、没自动重开？** 可能是主库数据目录正被 OneDrive 占用，或 Zotero 退出被同步/保存提示阻塞。稍等后手动打开 Zotero，归档快照数据已落盘，不影响。
- **归档库里插件没启用/看不到菜单？** 打开一次主库的「设置 → Zotero Archiver」会自动给所有归档库同步并启用插件。
- **恢复的附件打不开？** 确认归档库的链接附件目录（`D:/Zotero-Archive/<名称>/attachments`）存在。
- **改完路径/配置要重新打包？** 是的，改 `addon/` 后运行 `plugin/build-xpi.ps1` 重新生成 xpi。
